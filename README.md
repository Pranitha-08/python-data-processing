# Data Engineering Utility Library

A Python-based utility library designed to support common **Data Engineering tasks** such as file processing, data transformation, logging, streaming, and pipeline management.

## 🚀 Project Overview

This project provides reusable Python utilities that can be used to build reliable and maintainable data processing pipelines.

The project demonstrates practical Data Engineering concepts including:

* File parsing and processing
* Data source handling
* Data transformation
* Logging and monitoring
* Pipeline session management
* Streaming data processing
* Error handling
* Unit testing
* Python package development

## ▶️ Getting Started

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate to the project:

```bash
cd de_utils
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate the virtual environment.

Install dependencies:

```bash
pip install -r requirements.txt
```

## 🧪 Running Tests

Run the test suite using:

```bash
pytest
```
